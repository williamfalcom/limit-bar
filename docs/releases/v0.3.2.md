# limit-bar v0.3.2

A reliability release. Threshold notifications, wake refresh, and multi-account Codex now work as documented, and a stuck CLI can no longer freeze updates for every account.

## Fixed

- **80% notifications now appear.** limit-bar asks for notification permission at first launch (only if you have not decided yet) and also delivers under provisional authorization. Polling starts before the prompt, so quota data loads while it is open.
- **Waking the Mac refreshes stale data.** The wake handler now listens on the workspace notification center, where macOS posts the event.
- **Each Codex account shows its own limits.** The account's `CODEX_HOME` override is passed to `codex app-server`; accounts without an override keep the inherited environment.
- **A silent Codex or Copilot CLI no longer freezes polling.** CLI exchanges have a hard deadline (Codex 6 s, Copilot 15 s), and the process is stopped afterwards. Other accounts keep updating.
- **No crash when a CLI exits early.** Writing to a CLI that already exited now fails with an error instead of terminating limit-bar with `SIGPIPE`.
- **Copilot no longer hangs when both responses arrive together.** The reader keeps every buffered response frame.
- **Complete translations.** The Codex sign-in instruction, Copilot sign-in message, context-menu items, and network error message now appear in English, Brazilian Portuguese, and Spanish.

## Validation

- Swift Testing: **186 passed, 0 failed, 0 skipped** (151 in v0.3.0).
- An independent verifier checked every acceptance criterion and injected faults into an isolated copy; the final suite detects all 21 faults that count toward the verdict. Report: `.specs/features/reliability-fixes/validation.md`.
- **Manual check before publication:** grant the notification permission on first launch and push one window past 80%; exactly one notification should appear.

## Install

1. Download `limit-bar-v0.3.2.dmg` or `limit-bar-v0.3.2.zip` from this release.
2. Copy `limit-bar.app` to `/Applications`, or drag it from the DMG.
3. The app is ad-hoc signed, not Developer ID signed or notarized. macOS may block the first launch; use **Open Anyway** in **System Settings → Privacy & Security**, or right-click the app and choose **Open** where supported, only if you trust this download.

To verify a download, place it beside `limit-bar-v0.3.2-SHA256SUMS.txt` and compare its SHA-256 hash with the matching entry. With both archives downloaded, run:

```sh
shasum -a 256 -c limit-bar-v0.3.2-SHA256SUMS.txt
```

## Requirements

- macOS 14 or later.
- Universal app for Apple silicon and Intel Macs.
- An OpenCode Go account for browser sign-in, or an OpenCode API key. OpenCode CLI V2 is not required for this provider.
- Authenticated Claude Code, Codex, or GitHub Copilot CLI for the respective optional provider integrations.
