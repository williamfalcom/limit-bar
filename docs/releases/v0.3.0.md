# limit-bar v0.3.0

OpenCode Go now supports browser sign-in through a separate limit-bar-owned OAuth session, alongside the existing API-key option.

## Added

- Browser-first OpenCode Go setup with a device code, approval progress, and cancellation.
- Account-scoped OAuth credentials in the macOS Keychain, automatic refresh, and serialized refresh-token rotation.
- Method-specific account repair: reconnect through the browser or replace an API key without changing the account identity.
- English, Brazilian Portuguese, and Spanish authentication messages and setup instructions.

## Improved

- Existing OpenCode API-key accounts continue working without migration; rolling, weekly, and monthly quota windows remain available with either method.
- OpenCode authentication is independent of the CLI V2 session: limit-bar does not read or modify its credential database.
- Last-known quota data remains visible when an OpenCode account needs reauthentication.
- Account removal reports local credential-cleanup failures and warns that removing an OAuth account does not revoke its remote Console session.
- Updated multilingual documentation and installation screenshots since v0.2.0.

## Install

1. Download `limit-bar-v0.3.0.dmg` or `limit-bar-v0.3.0.zip` from this release.
2. Copy `limit-bar.app` to `/Applications`, or drag it from the DMG.
3. The app is ad-hoc signed, not Developer ID signed or notarized. macOS may block the first launch; use **Open Anyway** in **System Settings → Privacy & Security**, or right-click the app and choose **Open** where supported, only if you trust this download.

To verify a download, place it beside `limit-bar-v0.3.0-SHA256SUMS.txt` and compare its SHA-256 hash with the matching entry. With both archives downloaded, run:

```sh
shasum -a 256 -c limit-bar-v0.3.0-SHA256SUMS.txt
```

## Requirements

- macOS 14 or later.
- Universal app for Apple silicon and Intel Macs.
- An OpenCode Go account for browser sign-in, or an OpenCode API key. OpenCode CLI V2 is not required for this provider.
- Authenticated Claude Code, Codex, or GitHub Copilot CLI for the respective optional provider integrations.
